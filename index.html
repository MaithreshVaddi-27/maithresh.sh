Multi-System Architecture Workbench

Interactive execution pipelines, live tool dispatch simulations, and staff-level engineering trade-offs across my core systems.

VECTOR PIPELINE TELEMETRY // LOCAL_INFERENCE_OLLAMA_7B
STAFF INTERVIEW DEFENSE: ARCHITECTURAL TRADEOFFS

Single-Pass Fused NLI vs. Multi-Pass Overhead: Traditional RAG reliability splits claim extraction and NLI entailment scoring into separate sequential LLM calls, adding 1,200ms–2,000ms latency. TrustRAG fuses extraction and strict citation scoring into a single constrained JSON output schema, slashing verification latency by ~62% on local 7B models.

Bounded LangGraph recovery (2 attempts max): Rather than entering nondeterministic agentic retry loops, TrustRAG classifies verification failures (Missing Context vs. Unsupported Claim) and executes a budget-aware recovery sequence (rewrite → re-retrieve → regenerate), capped at 2 attempts. If reliability threshold (τ ≥ 0.75) remains unreached, it returns an explicit ABSTAIN token instead of a plausible hallucination.

MCP TOOL ROUTING TELEMETRY // LANGGRAPH_REACT_MACHINE
STAFF INTERVIEW DEFENSE: SINGLE AGENT VS. SWARM INFLATION

Why I Killed the 3-Agent Swarm: An early prototype utilized three discrete agents (Query Planner, Document Retriever, and Answer Synthesizer). Production profiling revealed a 350% token inflation and 4.9s added latency purely from conversational serialization. By collapsing into a single LangGraph state machine with dynamic MCP tool routing, latency dropped from 6.8s to 1.9s with zero quality degradation.

Standardized MCP Protocol: Decoupled tool execution from proprietary LLM vendor schemas by standardizing on Model Context Protocol (MCP) JSON-RPC 2.0 endpoints. This allows live web retrieval tools (Tavily via Composio) and local document parsers to swap transparently without rewriting prompt topologies.

ATS EVIDENCE MATCHER TELEMETRY // METAL_MPS_AUTO_OFFLOAD
STAFF INTERVIEW DEFENSE: DETERMINISTIC MATCHING VS. LLM EMBELLISHMENT

Why I Refuse Creative Generative Rewriting: Most AI resume tools prompt LLMs to "rewrite bullets to pass ATS", frequently hallucinating unverified tools and fabricated metrics. Resume Crew operates strictly on deterministic claim verification: it extracts job requirements as an explicit checklist and matches each line item against verified textual spans in the user's CV with citation bounds.

Zero-Telemetry Offline Privacy: Resumes contain personally identifiable information (PII). By default, all telemetry is disabled, network calls are isolated, and the entire matching pipeline executes locally via Ollama with automated Metal / CUDA GPU detection.

2-STAGE DEDUP & AGENT MESH TELEMETRY // LANGGRAPH_RESILIENT_CIRCUIT
STAFF INTERVIEW DEFENSE: TWO-STAGE DEDUP & RESILIENT MESH

Why Naive SQL Unique Keys Fail: Across multi-board job aggregators, identical positions appear with subtle variances (e.g. "Sr. Backend Engineer" vs "Senior Backend Developer"). CareerOS-Pro implements a 2-stage filter: first, deterministic canonical normalization (lowercase, stripped punctuation, geo-bucketed) eliminates 70% of exact duplicates without vector computation. Second, remaining candidates pass through a high-threshold ChromaDB cosine similarity cluster before reaching database ingestion.

Fault-Tolerant Circuit Breakers: Every adapter operates in an isolated LangGraph node with stateful circuit breaking. If Adzuna or Remotive encounters HTTP 429 rate limits or network degradation, the health monitor degrades the pipeline gracefully without halting downstream matching.

Standard RAG systems fail silently — this doesn't. A local-first reliability loop: hybrid retrieve (dense BGE-small + BM25 + RRF) → grounded generation → claim decomposition fused with NLI verification in one call → SHA-256 + temporal-window evidence audit → reliability scoring against configurable thresholds → if it fails, a budget-aware LangGraph recovery loop (rewrite → re-retrieve → regenerate, capped at 2 attempts) → grounded answer or explicit ABSTAIN. Recovery doesn't just retry blindly — it diagnoses why verification failed and picks the matching fix: query rewrite, wider re-retrieval, or a free regenerate, bounded to one round.
